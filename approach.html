Approach

How we create synthetic security data

We simulate realistic organizations end to end and record what their defenders would see. The result is data that looks and behaves like the real thing, with complete ground truth and no sensitive information.

From simulation to dataset

01

Model realistic environments

Simulated organizations with users, workstations, servers and the network activity that connects them.

02

Generate everyday activity

Simulated employees browse, email, write documents and log in, producing the background noise real defenders face every day.

03

Emulate adversary behavior

Known attack techniques, aligned with the MITRE ATT&CK® framework, are carried out in a controlled setting alongside normal activity.

04

Capture what defenders see

Logs, endpoint telemetry and detection alerts are collected the same way a security team would collect them.

05

Label and package

Every event is tied to ground truth (benign or malicious, and which technique) and delivered as a clean, privacy-safe dataset.

The advantages of simulated data

Privacy-safe

No real people, credentials or networks are involved, so datasets can be shared without legal review.

Fully labeled

Because we control the scenario, we know exactly which events are malicious and why.

Controllable and repeatable

Scenarios can be adjusted and re-run, so datasets can be tailored and reproduced.
