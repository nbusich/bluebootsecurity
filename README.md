# BlueBoot Security website

Static site for BlueBoot Security (independent SOC evaluation, plus labeled security datasets for training), built with [Bootstrap 5.3](https://getbootstrap.com/) and Bootstrap Icons loaded from the jsDelivr CDN. No build step; served by GitHub Pages from the `main` branch root.

- `index.html`: the whole site, one page with anchor sections (problem, how it works, offer, contact).
- `custom.css`: brand colours (light and dark) and the wordmark, layered on top of Bootstrap.
- `logo.svg`, `favicon.svg`: the logo and the shield icon.
