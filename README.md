# shoo.ai website

Static site for shoo.ai (synthetic cybersecurity datasets), built with [Bootstrap 5.3](https://getbootstrap.com/) and Bootstrap Icons loaded from the jsDelivr CDN. No build step; served by GitHub Pages from the `main` branch root.

- `index.html`, `mission.html`, `approach.html`, `contact.html`: the pages. Layouts follow Bootstrap's official examples (navbar, heroes, features, jumbotron, footers). The navbar and footer are repeated in each page, so edit all four when changing them.
- `custom.css`: brand colours and the wordmark, layered on top of Bootstrap.
- `logo.svg`, `favicon.svg`: the logo and the shield icon.
